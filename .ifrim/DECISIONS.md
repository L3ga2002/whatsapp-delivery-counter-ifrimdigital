# Decisions - WhatsApp Delivery Counter

## 2026-06-12

- Project initialized in the IfrimDigital multi-project system.
- Codex is the coordinator.
- OpenClaw and Claude Code are specialist tools used per task.
- Project memory lives in .ifrim/.

- The main counting mode is a custom selected date/time interval.
- "Last 7 days" may exist only as a preset later, not as the core rule.
- Direct WhatsApp scraping/live group automation is out of MVP.
